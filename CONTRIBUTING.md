# Contributing to AnimeVerse

Thanks for helping improve AnimeVerse.

## Before submitting changes

1. Fork the repository and create a focused branch.
2. Keep UI changes responsive on mobile and desktop.
3. Do not commit secrets, API keys, passwords, or private media.
4. Use only artwork/media you are licensed to publish.
5. Make sure every new button or navigation item has a working action.
6. Update documentation when behavior or setup changes.

## Pull requests

Describe what changed, how it was tested, and any database migration required. Keep unrelated refactors out of the same pull request when possible.
